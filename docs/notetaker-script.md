# Note-Taker Script — Pilot Study

**Your role:** Silent observer. Do NOT interact with participants unless absolutely necessary.
Your notes are critical research data — they capture what the recording might miss (body language, screen states, timing).

---

- [ ] Printed note-taking sheets (or laptop with blank doc open)
- [ ] Timer/stopwatch ready (start when coding begins at ~0:15)
- [ ] Seated where you can see all participants' screens

## Note Format

Use this template for every observation:

```
[MM:SS] [WHO] [WHAT HAPPENED] [REACTION/CONTEXT]
```

**Examples:**
```
[12:30] P2 typed @AI "what should I work on next?" — AI responded with task list, P2 nodded and started working
[18:45] P1 looked confused at task tracker, squinted, scrolled up and down, then ignored it
[22:10] P3 opened ChatGPT in browser — was trying to debug a function, didn't use @AI
[31:00] P1 and P2 talking about same file — seem to be duplicating work, neither checked task tracker
```

---

## What to Watch For During Coding (0:15 - 0:45)

| Category | What to Note |
|----------|-------------|
| **@AI Usage** | Every @AI message: who sent it, what they asked, did the response help, did they act on it or ignore it |
| **Confusion/Frustration** | Sighs, pauses >10s, "what?", "huh?", furrowed brows, re-reading same thing — note who + when + what they were doing |
| **Collaboration Moments** | When participants talk to each other, coordinate, or fail to coordinate |
| **Task Tracker** | Do they check it? How often? Do they mark tasks complete? Do they complain about it? |
| **Workarounds** | Any time someone bypasses the tool — uses Slack, manually divides work, ignores AI suggestion |
| **AI Division Reactions** | First impressions when tasks are assigned — agreement, confusion, pushback, silence |
| **Tool Switching** | When they leave the extension for Copilot/ChatGPT — what triggered the switch |
| **Technical Issues** | Any bugs, crashes, slow responses, UI glitches — note exact time and what happened |

---

## What to Watch For During Discussion (0:48 - 1:05)

- Write down **key quotes verbatim** (even partial) — these are gold for the thesis
- Note **disagreements** between participants
- Note when **everyone agrees** on something — that's a strong signal
- Note **body language**: nodding, shaking head, leaning forward (engaged), leaning back (disengaged)
